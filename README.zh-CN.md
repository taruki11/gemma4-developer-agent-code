# Gemma 4 Developer Agent

> 代码快照发布说明：仅含筛选源码，不含模型、数据、日志或凭据。

本项目记录一个软件开发 Agent 的环境检查、工具调用和代码补丁评测流程，并保留失败分析与协议边界。

## 范围

- 开发 Agent 运行与结果收集脚本
- 受控工具集和补丁验证流程
- 固定任务集上的诊断与错误归因

## 复现

使用仓库提供的脚本和锁定依赖运行。数据集、Kaggle 账户信息、模型权重、wheelhouse、评测输出和私有 notebook 不属于公开源码包。

## 已知限制

有限任务集的结果仅是诊断性证据。没有提交排行榜或官方效果声明；未通过门槛的候选应继续标记为未通过。
