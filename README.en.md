# Gemma 4 Developer Agent

> Code-only source snapshot. No models, datasets, logs, or credentials are included.

This project documents environment checks, tool use, and patch evaluation for a software-development agent, including failure analysis and protocol boundaries.

## Scope

- Agent execution and result-collection scripts
- Controlled tool sets and patch-verification workflow
- Diagnostics and error attribution on fixed tasks

## Reproduction

Run the provided scripts with the pinned dependencies. Datasets, Kaggle account material, model weights, wheelhouses, evaluation outputs, and private notebooks are excluded from a public source package.

## Limitations

Results on a limited task set are diagnostic evidence only. No leaderboard submission or official performance claim is made; candidates that fail a gate should remain labeled as failed.
